# /deploy - 部署流程

**触发词**: "准备部署"、"要上线了"、"deploy 一下"、"发布"

---

## 命令语法

```
/deploy [environment] [--dry-run=false|true] [--skip-tests=false|true] [--version=auto|X.Y.Z]
```

## 参数说明

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `environment` | string | 否 | `staging` | 部署目标环境：`dev`、`staging`、`production` |
| `--dry-run` | bool | 否 | `false` | 预演模式：模拟部署流程但不实际执行变更 |
| `--skip-tests` | bool | 否 | `false` | 是否跳过测试阶段（仅紧急修复时允许） |
| `--version` | string | 否 | `auto` | 部署版本号：`auto`（自动生成）或手动指定 `X.Y.Z` |

## 触发场景

- 功能开发完成并通过测试，需要发布到预发布/生产环境
- 紧急 Bug 修复后，需要快速上线
- 定期版本迭代，按计划发布新版本
- 配置变更（环境变量、Nginx 配置）需要同步到各环境
- 回滚操作：将生产环境回退到上一个稳定版本

## 前置条件

1. 代码已通过代码审查（`review` 阶段）
2. 所有测试通过（除非 `--skip-tests=true` 且已说明原因）
3. 目标环境的部署配置已就绪（`docker-compose.yml`、Secrets、环境变量）
4. 数据库迁移脚本已准备就绪（如有 Schema 变更）
5. 回滚方案已确认（上一个稳定版本的镜像/代码标签）

## 执行流程

1. **环境确认** — 确认目标环境配置、当前运行版本、部署窗口时间
2. **预检查** — 检查代码状态、测试通过情况、构建产物完整性
3. **版本标记** — 如 `--version=auto`，按语义化版本规范生成版本号并打 Tag
4. **构建镜像** — 构建 Docker 镜像，推送到镜像仓库
5. **数据库迁移** — 如存在未执行的迁移脚本，先执行 `alembic upgrade head`
6. **预演检查** — 如 `--dry-run=true`，输出变更清单但不实际部署
7. **服务部署** — 按蓝绿/滚动策略更新服务，确保零停机或最小停机
8. **健康检查** — 验证服务启动成功、依赖服务可达、关键接口响应正常
9. **流量切换** — 更新 Nginx/负载均衡指向新版本
10. **部署验证** — 执行 smoke test，确认核心功能正常
11. **通知归档** — 记录部署日志，通知相关人员

## 产出物

- **部署检查清单**：环境确认、预检查、健康检查逐项结果
- **部署命令**：实际执行的部署命令序列
- **部署后验证报告**：服务状态、接口测试、日志检查结果
- **部署日志**：版本号、部署时间、变更内容、执行人
- **回滚指令**：如需回滚，提供一键回滚命令

## 错误处理

| 常见错误 | 处理方式 |
|----------|----------|
| 测试未通过 | 终止部署，要求修复后重新触发 `/deploy` |
| 数据库迁移失败 | 回滚迁移，检查脚本合法性，修复后重试 |
| 健康检查失败 | 自动回滚到上一个稳定版本，保留日志供排查 |
| 镜像构建失败 | 检查 Dockerfile 和依赖，修复后重新构建 |
| 环境变量缺失 | 终止部署，提示补充缺失的 Secrets/ConfigMap |
| 部署超时 | 检查服务启动日志，确认资源是否充足（CPU/内存） |
| 回滚失败 | 人工介入，手动切换流量并排查问题 |

## 示例

### 示例 1：标准预发布部署

```
/deploy staging --version=auto
```

**预期输出**：
- 生成版本 `v1.4.3`
- 构建并推送镜像 `app:v1.4.3`
- 执行数据库迁移（如有）
- 部署到 staging 环境
- 健康检查通过，smoke test 通过
- 部署完成

### 示例 2：生产环境紧急修复（跳过测试）

```
/deploy production --skip-tests=true --version=1.4.3-hotfix.1
```

**预期输出**：
- 警告：跳过测试阶段，需记录原因
- 构建 hotfix 镜像
- 快速部署到生产环境
- 健康检查通过
- 部署完成后立即补充测试并审查
