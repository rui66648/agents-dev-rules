# 阈值表 — 图里红黄绿的唯一来源（RULE-054 §4）

> 任何一张图上的灯（绿/黄/红）都必须坐在本表某一行的「指标」上；门禁逐行核对，**句子里没有本表指标名的灯 = FAIL**。
> 档位不许拍脑袋：数值档一律写明**标定依据**（实测分布 / 单位换算），标定样本记在「口径」列末尾。
> 新增图或换口径，先改本表再改图；改档要在对应图的「变化」段留一条 delta。
> 判档次序由取数器实现为 **红 → 绿 → 黄**，故黄档写成「≤上界」而不是区间串。

## 填写纪律

- **口径列必须是可算式**（分子/分母写清），不接受"看情况"；数值档必须能被解析成比较式（`≤n` / `≥n` / `<n` / `>n` / `=n`），区间请拆成上下界两档。
- **数据源列必须指向一个命令、端点或表**；纯人工填的数要在源后标 `人工` 与复核日期。
- **责任人必须是具体的人或角色**，不能是"团队"。
- 档位改了要在对应图的「变化」段留 delta（旧口径 → 新口径），否则视为口径漂移。
- 冻结 / 档案仓：本表可整体不适用，但对应槽位必须在 frontmatter 写 `status: not_applicable` + 理由，不留空壳图与假读数。
